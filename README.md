# Project Description
This project structure contains the following folders:
  1. data: containing the csv files matches and deliveries
  2. server: containing the individual functions for the ipl project scenarios.
  3. public: containing the output JSON files generated by the scripts.

## How to run the project
- Step 1: Download the code / clone the repository and make sure your machine has Node.js installed.
- Step 2: Open a terminal in the project root (the folder containing `package.json`) and install the dependencies:
  
  ```
  npm install
  ```
- Step 3: Generate the output by running each scenario from the project root. Each command reads the CSV files from `src/data` and writes a JSON file to `src/public/output`:
  ```
  npm run q1
  npm run q2
  npm run q3
  npm run q4
  ```
- Step 4: Open the generated JSON files in `src/public/output` to see the results.

## Scripts
| Command | Problem | Output file |
|---------|---------|-------------|
| `npm run q1` | Number of matches played per year for all the years in IPL | `src/public/output/matchesPerYear.json` |
| `npm run q2` | Number of matches won per team per year in IPL | `src/public/output/matchesWonPerTeamPerYear.json` |
| `npm run q3` | Extra runs conceded per team in the year 2016 | `src/public/output/extraRunsPerTeam2016.json` |
| `npm run q4` | Top 10 economical bowlers in the year 2015 | `src/public/output/topEconomicalBowlers2015.json` |

## Tech used
- Node.js
- PapaParse (for reading the CSV files)
